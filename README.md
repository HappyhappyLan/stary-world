## 使用方法

### 添加新地点
1. 点击"➕ 添加新地点"按钮
2. 选择方式:
   - **方式一**: 选择省份-城市-区县,坐标自动填充
   - **方式二**: 在小地图上点击选点,系统自动判断国家
3. 填写地点名称(自动填充可修改)
4. 选择点亮时间(年-月-日)
5. 填写旅行记忆(可选)
6. 上传照片(支持多张,可选)
7. 点击"保存"按钮
8. 数据自动保存到localStorage
9. 点击"💾 导出数据"按钮永久保存

### 地图选点智能识别
- 系统自动根据经纬度判断所属国家
- 中国境内坐标自动识别为中国
- 无法匹配标准省份的地点自动归类为"其他"
- 在侧边栏查看: 国家 > 省份列表 > 🗺️ 其他

### 生成足迹卡片
1. 在侧边栏点击任意地点查看详情
2. 滚动到详情页底部
3. 点击"生成足迹卡片"按钮
4. 自动下载PNG格式图片
5. 地点名称自动简称化(去掉"市"、"省"等后缀)

### 查看和管理地点
- **侧边栏**: 查看所有已标记地点，支持搜索
- **地图标记**: 点击地图标记查看详情
- **详情页面**: 查看完整信息，可编辑点亮时间

### 搜索地点
- 在侧边栏搜索框输入关键词
- 支持按城市名称搜索（如"昆明"）
- 支持按省份搜索（如"云南"，显示云南省所有城市）

## 数据保存说明

### 临时保存 (localStorage)
- 添加或修改地点后自动保存
- 刷新页面后可选择恢复
- 浏览器关闭前有效

### 永久保存 (导出文件)
1. 点击统计面板中的"💾 导出数据"按钮
2. 自动下载data.js文件
3. 将下载的data.js文件替换桌面上的同名文件
4. 下次打开页面时数据将永久保留

## 常见问题

### Q: 地图选点后为什么省份显示"其他"?
A: 系统根据经纬度自动判断国家,但如果该坐标无法匹配到标准省市数据,会自动归类为"其他"。这是正常的,不影响使用。

### Q: 如何修改已保存的地点?
A: 点击侧边栏中的地点名称,打开详情页后可以:
- 编辑点亮时间
- 添加/删除照片
- 添加/删除评论
- 删除地点

### Q: 数据会丢失吗?
A: 数据会自动保存到localStorage,但为了永久保存,请务必点击"导出数据"按钮并替换data.js文件。
